# Login & Signup App

A simple full-stack authentication app built while learning Node.js and Express.

## Built With

* Node.js
* Express
* PostgreSQL
* EJS
* bcrypt
* express-session
* express-validator

## Features

* User signup and login
* Password hashing with bcrypt
* Session-based authentication
* Protected profile page
* Logout
* Form validation
* PostgreSQL database
